# 🍀 น้องโชค — ผู้ช่วย AI ที่เรียนรู้ได้

น้องโชคเป็นแอปใหม่บนหน้าเมนูหลัก (ทุกคนเห็น) อยู่ในไฟล์ `chok.html`
หลังบ้านอยู่ในไฟล์ `apps-script/NongChok.gs` ซึ่งต้องนำไปวางในโปรเจกต์ Apps Script เอง

## น้องโชคเรียนรู้ได้ยังไง

ทุกอย่างที่น้องโชคเรียนรู้จะเก็บไว้ในชีต **"น้องโชค — ความรู้"**
ใช้ครั้งแรกเมื่อไหร่ ระบบจะสร้างชีตนี้ใน Google Drive ของเจ้าของสคริปต์ให้เอง
น้องโชคอ่านคลังความรู้นี้ทุกครั้งก่อนตอบ

| วิธีสอน | ทำยังไง |
|---|---|
| 📚 สอนตรงๆ | แท็บ **สอน** → ใส่หัวข้อ + ความรู้ → บันทึก |
| 💬 สอนระหว่างคุย | พิมพ์ เช่น *"จำไว้นะว่า โปร S26 ลด 3,000 ถึงสิ้นเดือน"* น้องโชคจะบันทึกเองแล้วขึ้นว่า 🧠 จำไว้แล้ว |
| ✏️ แก้คำตอบที่ผิด | กด **✏️ ไม่ถูก สอนใหม่** ใต้คำตอบ → พิมพ์คำตอบที่ถูก |

- ถ้าความรู้ใหม่ขัดกับของเดิม น้องโชคจะเชื่อรายการที่ใหม่กว่า
- ผู้จัดการ (รหัส 15628) ลบความรู้ที่ผิดหรือหมดอายุได้ในแท็บ **สอน** หรือจะแก้ในชีตโดยตรงก็ได้
- น้องโชคจะไม่จำข้อมูลส่วนตัวของลูกค้าและรหัสผ่าน

## ติดตั้ง (ทำครั้งเดียว)

1. **รับ API key** ที่ https://console.anthropic.com → API Keys → Create Key
2. เปิดโปรเจกต์ Apps Script ของ SUPER APP (ตัวเดียวกับลิงก์ใน `gas.js`)
3. **เพิ่มไฟล์** ➕ → Script → ตั้งชื่อ `NongChok` → วางโค้ดทั้งหมดจาก `apps-script/NongChok.gs`
4. **ตั้งคีย์**: ⚙️ Project Settings → Script Properties → Add script property
   - Property: `ANTHROPIC_API_KEY`
   - Value: คีย์จากข้อ 1 (ห้ามใส่คีย์ไว้ในโค้ดหรือใน GitHub)
5. **เปิดทางให้แอป `chok`** ใน `API.gs`: ตัวรับคำสั่งจะได้ข้อมูล `{ app: 'chok', fn: 'ชื่อฟังก์ชัน', args: [...] }`
   ถ้า `API.gs` มีรายชื่อฟังก์ชันที่อนุญาตแยกตามแอป ให้เพิ่มแอป `chok` เข้าไปแบบนี้:
   ```js
   chok: ['chokChat', 'chokTeach', 'chokFeedback', 'chokListKnowledge', 'chokDeleteKnowledge'],
   ```
   ทุกคนที่ล็อกอินแล้วควรเรียกได้ (เหมือนแอป Ranking / รวมภาพ)
6. **Deploy ใหม่**: Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy
   (ลิงก์ `/exec` เท่าเดิม ไม่ต้องแก้ `gas.js`)
7. ครั้งแรกที่รัน Google จะขอสิทธิ์ **เชื่อมต่อบริการภายนอก** (เรียก API) และ **สร้างชีต** ให้กด Allow

## ค่าใช้จ่าย

น้องโชคใช้โมเดล `claude-opus-5-5` ที่ระดับ effort `low` (ตอบเร็ว ประหยัด) และคิดเงินตามการใช้งานจริงในบัญชี Anthropic
ตั้งวงเงินสูงสุดต่อเดือนได้ที่ console.anthropic.com → Settings → Limits

## หมายเหตุ

- ข้อมูลว่าใครกำลังคุยหรือสอน ส่งมาจากหน้าเว็บ ถ้า `API.gs` ตรวจ token แล้วรู้รหัสพนักงานจริง
  ควรเอารหัสนั้นใส่แทน `who` ใน `chokDeleteKnowledge` เพื่อกันคนปลอมรหัสผู้จัดการ
- ถ้าความรู้เยอะเกินประมาณ 60,000 ตัวอักษร น้องโชคจะเลือกเฉพาะเรื่องที่ใกล้เคียงกับคำถามมาใช้ตอบ
